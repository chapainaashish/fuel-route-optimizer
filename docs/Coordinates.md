# Station Coordinates: How Latitude/Longitude Were Added

The fuel price CSV (`fuel-prices-for-be-assessment.csv`) has **no latitude or longitude**. Its columns are:

```
OPIS Truckstop ID, Truckstop Name, Address, City, State, Rack ID, Retail Price
```

To find which stations lie near a driving route, and how far along the route each one is, we need lat and long for every station. Geocoding 8K rows through an API at request time would be slow and would break the "few external API calls" requirement. So, coordinates are saved **once, offline**, by matching each station's `City` + `State` against free city-coordinate datasets. No API calls are used here.

Addresses in the CSV are highway exits (e.g. `I-44, EXIT 283 & US-69`), which street-level geocoders handle poorly. So, City + state are used as the key.

**Accuracy:** coordinates are **city-level** (the city's center point), not the exact truck stop location. Exact-address geocoding is a possible future improvement.

## Files

| File                                | Role                                                           | Source / where it came from                                                                |
| ----------------------------------- | -------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| `fuel-prices-for-be-assessment.csv` | Input. Fuel stations and prices (no coordinates)               | Provided with the assignment                                                               |
| `uscities.csv`                      | Lookup table 1. Main US cities with `lat`, `lng`, `population` | SimpleMaps, free "Basic" US Cities database: https://simplemaps.com/data/us-cities         |
| `US.txt` (from `US.zip`)            | Lookup table 2. Small places and unincorporated communities    | GeoNames: https://download.geonames.org/export/dump/ (download `US.zip`, extract `US.txt`) |
| `add_cords.py`                      | Pass 1. Join stations to `uscities.csv`                        | Written for this project                                                                   |
| `add_coords_pass2.py`               | Pass 2. Drop non-US rows, fill gaps from GeoNames              | Written for this project                                                                   |
| `add_coords_pass3.py`               | Pass 3. Manual overrides for the last unmatched cities         | Written for this project                                                                   |
| `fuel_prices_with_coords.csv`       | **Output.** Original columns plus `lat` and `lon`              | Generated by the scripts                                                                   |

**NOTE: I have only kept the sample row in US.txt to reduce the file size. You should download it from the above link before running the script**

## Run order

```powershell
python .\add_cords.py            # pass 1: SimpleMaps join, writes fuel_prices_with_coords.csv
python .\add_coords_pass2.py     # pass 2: drops Canada, fills from GeoNames (needs US.txt)
python .\add_coords_pass3.py     # pass 3: manual overrides for the last 18 cities
```

### Pass 1: `add_cords.py` (SimpleMaps join)

1. Read `uscities.csv` (`city_ascii`, `state_id`, `lat`, `lng`, `population`).
2. Normalize city names with `norm_city()`: lowercase, strip whitespace, expand `St.`/`Ste.`/`Ft.`/`Mt.` to `saint`/`sainte`/`fort`/`mount`, remove punctuation, collapse spaces.
3. When the same city name appears twice in a state, keep the **most populous** one.
4. Strip trailing whitespace from the fuel CSV (e.g. `"New Castle      "`).
5. Join on `(normalized city, state)`. A second fallback join ignores spaces entirely, so `Mc Donald` matches `McDonald`.
6. Write `fuel_prices_with_coords.csv` (all original rows kept, plus `lat` and `lon`) and `unmatched_cities.csv`.

**Result:** 6,187 of 6,738 unique stations matched (91.8%).

Most misses were not real misses. The CSV includes Canadian truck stops (provinces `AB`, `BC`, and others), and the assignment was the USA only. So, we need to remove the Canadian truck stops.

### Pass 2: `add_coords_pass2.py` (drop Canada, add GeoNames)

1. Keep only rows whose `State` is one of the 50 US states plus DC. **112 non-US stations were dropped.**
2. Load `US.txt` (tab-separated, no header). Used columns: name, latitude, longitude, feature class, state (admin1), population. Keep only feature class `P` (populated places).
3. Normalize names the same way and keep the most populous match per `(name, state)`.
4. Fill `lat`/`lon` only where still empty, so good SimpleMaps matches are never overwritten.

**Result:** 6,603 of 6,626 US stations matched (99.7%). 18 cities remained.

## Assumptions and known limitations

- **City-level coordinates.** All stations in the same city share one point. Positions can be several miles from the real truck stop.
- **Duplicate station IDs are not removed by these scripts.** The same `OPIS Truckstop ID` appears multiple times with different prices (e.g. ID 105 appears six times). Deduplication happens at database load time, keeping the **lowest price** per station.
- **Canadian stations are excluded**, since all trips are within the USA.
- **Duplicate city names** within a state resolve to the most populous city.
- **Manual overrides** (18 cities) were entered by hand.
